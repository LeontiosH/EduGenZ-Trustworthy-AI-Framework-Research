# Data access and embargo

Participant-level response data remain under the EduGenZ project embargo and are not distributed in this public release. This includes both wide and long response tables, participant-level demographic records and individual multivariate coordinates. Original submission timestamps are also excluded.

The repository provides analysis code, questionnaire and variable documentation, aggregate numerical results, and aggregate figures. These materials can be inspected without access to the respondent records. Re-running the analyses requires an authorised copy of the participant-level dataset. The public package does not offer or imply unrestricted access during the embargo.

The data-release arrangements will be updated following expiry of the project embargo and the applicable release authorisation. No calendar end date is assigned in this package because a confirmed date was not supplied. Future participant-level release is subject to the study's consent and disclosure requirements.

Aggregate reference results summarise the published analyses. They are not a replacement for the embargoed participant-level dataset. The illustrative cross-context matrices are analytical specifications, not observations from additional samples.
