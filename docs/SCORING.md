# Scoring and coverage

The analysis data contain 87 × 84 = 7,308 ratings: 6,462 relevant (1–3) and 846 non-relevant (0). There are no missing item codes.

Primary means pool non-zero item ratings in each requirement/subcategory, then multiply by 10/3. This gives a possible importance range of 3.333... to 10, not 0 to 10. Relevance is the proportion of item judgements coded 1–3. Participant profiles average a participant's non-zero ratings; an all-zero grouping has an undefined importance score.

The primary requirement PCA uses 79 complete profiles. Subcategory PCA uses 68 complete profiles. The student subset has 63 respondents (57 student nonmembers and six student members); 57 have complete requirement profiles. Whole-participant bootstrap resampling uses the seeds in each script and preserves the source row order.

Descriptive and relevance–importance intervals use 50,000 samples (seed 20261105); robustness rank credits use 20,000 samples; student analyses use 50,000 draws with seeds 20261106 and 20261107, and 20261206/20261207 for centred profiles.
